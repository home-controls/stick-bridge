# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and patient. Criticise code and ideas, not people. Harassment,
insults, discrimination and publishing other people's private information are not accepted, in issues,
pull requests, discussions or anywhere else this project is represented.

## Reporting

If someone's behaviour is a problem, tell the maintainer privately: open a private report on this
repository's **Security** tab (**Report a vulnerability**) and start the title with "Conduct:". Reports
are kept confidential.

The maintainer may edit or remove comments, close threads, or block people who don't follow this code,
as the Contributor Covenant's enforcement guidelines describe.
